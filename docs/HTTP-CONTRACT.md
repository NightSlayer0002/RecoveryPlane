# Console API contract

All routes prefix `/api`. Requests/responses JSON. Errors `{error: string, code?: string}`. Bearer session token held in sessionStorage. Demo login: POST `/api/auth/demo` body `{role:'ADMIN'|'OPERATOR'|'VIEWER'}` -> `{token,user:{id,name,role,organizationId,organizationName},demo:true}`. GET `/api/session` -> `{user,demo}`. GET `/api/health` -> `{status:'ok',mode:'local'|'postgres',demo:boolean}`. Non-demo users enter their provisioned access token.

GET `/api/cases` -> `{cases:Case[],stats:{open,awaitingConfirmation,recovered,total},members:User[]}`. Query `status` (OPEN/RESOLVED/CANCELLED/DISMISSED/all), `priority`, `integrationId`, `q`, `owner` optional. GET `/api/cases/:id` -> CaseDetail. PATCH `/api/cases/:id` body `{version,priority?,ownerId?:string|null,status?:'DISMISSED',note?:string}` -> CaseDetail. POST `/api/cases/:id/notes` `{text}` -> CaseDetail.

Case: `{id,number,title,message,organizationId,integrationId,integrationName,environment,workflow,step,entity:{type,id},context:Record<string,unknown>,priority:'LOW'|'MEDIUM'|'HIGH'|'CRITICAL',status:'OPEN'|'RESOLVED'|'CANCELLED'|'DISMISSED',recoveryStatus:'PENDING'|'QUEUED'|'AWAITING_CONFIRMATION'|'OUTCOME_UNKNOWN'|'SUCCEEDED'|'FAILED',ownerId:string|null,version,occurrenceCount,createdAt,updatedAt}` (dates ISO strings).

CaseDetail adds `{actions:Action[],commands:Command[],timeline:Audit[],relatedCases:Case[]}`. Action `{id,actionKey,label,description,version,riskLevel:'LOW'|'MEDIUM',requiresConfirmation:boolean,enabled:boolean,inputSchema:{type:'object',properties:Record<string,{type:'string'|'number'|'boolean',title?:string,description?:string,enum?:string[],minLength?:number,maxLength?:number,minimum?:number,maximum?:number}>,required?:string[]}}`. Command `{id,actionKey,actionLabel,status:'QUEUED'|'AWAITING_CONFIRMATION'|'OUTCOME_UNKNOWN'|'SUCCEEDED'|'FAILED'|'BLOCKED',input,createdAt,result?:{message,outcome,caseDisposition},deliveries:{id,attempt,status,error?,createdAt}[]}`. Audit `{id,eventType,actorName,message,createdAt}`.

POST `/api/cases/:id/actions/:actionId` body `{version,input:{},idempotencyKey:crypto.randomUUID(),confirmed:boolean}` -> `{command,case:CaseDetail}`. POST `/api/commands/:id/retry` `{}` redelivers existing unknown command, returns CaseDetail. All mutations operator/admin; integration settings admin only. VIEWER reads only.

GET `/api/integrations` -> `{integrations:Integration[]}`. Integration `{id,name,environment,callbackUrl,enabled,createdAt,lastEventAt:string|null,actions:Action[],caseCount}` (no secrets). POST `/api/integrations` `{name,environment,callbackUrl}` -> `{integration,reportingKey,signingSecret}` (show one-time credentials). PATCH `/api/integrations/:id` `{enabled:boolean}` -> Integration. POST `/api/integrations/:id/actions` `{actionKey,label,description,inputSchema,riskLevel,requiresConfirmation}` -> Action. PATCH `/api/integrations/:id/actions/:actionId` `{enabled:boolean}` -> Action. GET `/api/events` authenticated fetch SSE stream; small `data: {type:'invalidate'}` events; polling and focus-refetch required as fallback.

POST `/api/demo/scenarios` body `{scenario:'missing_country'|'duplicate_reports'|'lost_response'}` -> `{caseId,message}`; operators/admin only and only demo mode. Creates a real origin vendor and reports via SDK/HTTP. Lost-response scenario origin commits then first response is lost; reconciliation uses same command ID. GET `/api/demo/vendors` -> `{vendors:[{id,name,country,status,mutationCount}]}`.

GET `/api/activity` -> `{events:Audit[]}` tenant scoped (optional UI). GET `/api/metrics` -> `{total,open,recovered,cancelled,dismissed,unknown,recoveryRate,medianRecoveryMinutes}` computed from persisted cases. No invented time-series.
