# Library and asset credits

- [React](https://github.com/facebook/react): MIT. Component/rendering layer.
- [Motion for React](https://github.com/motiondivision/motion): MIT. Transitions and scroll-driven recovery walkthrough. Uses the public library API; no premium Motion+ example assets are included.
- [Lucide](https://github.com/lucide-icons/lucide): ISC. Icons used across navigation, actions and diagrams.
- [TanStack Query](https://github.com/TanStack/query): MIT. Server state and invalidation.
- [Vite](https://github.com/vitejs/vite): MIT. Development and production frontend builds.
- [PGlite](https://github.com/electric-sql/pglite): Apache-2.0. Embedded PostgreSQL for the local experience; PostgreSQL has its own permissive license.

Dependencies retain their own license notices in their installed packages. The complete dependency graph is pinned in `pnpm-lock.yaml`.

RecoveryPlane’s layouts, diagrams, product copy and styling are source code in this repository. No AI-generated raster artwork, stock photography, paid component templates, or copied product screenshots are bundled. System fonts avoid runtime font-service requests. Componentry and ShaderGradient were evaluated as design references; their assets are not distributed here.
